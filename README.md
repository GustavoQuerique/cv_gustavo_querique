#  Landing Page Pessoal

Landing page desenvolvida para apresentar meu perfil, habilidades, projetos e trajetória nos estudos de desenvolvimento de software.

O projeto foi criado utilizando HTML e CSS, com foco em organização visual, responsividade e apresentação de portfólio.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

##  Conteúdo da página

A landing page possui seções para:

- Apresentação pessoal
- Minha jornada de estudos
- Habilidades e tecnologias
- Projetos pessoais
- Informações adicionais
- Links para GitHub e LinkedIn

##  Projetos apresentados

Entre os projetos exibidos na página estão:

- Grimório D&D 5e
- Dado 3D
- Mais 5 Minutinhos

A seção de projetos apresenta alguns dos trabalhos desenvolvidos durante meus estudos.
